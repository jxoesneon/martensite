# Martensite

> **A retained-mode, GPU-accelerated graphical user interface framework for Rust.**

Named after the crystalline phase of hardened steel, **Martensite** is a
pure-Rust, retained-mode GUI framework designed for desktop applications
and technical software.

The framework provides direct GPU compute rendering via WGPU, a
fine-grained push-pull reactive state model, and an arena-based widget
hierarchy. It is architected for predictable latency, low idle resource
consumption, and straightforward cross-platform deployment using
standard Rust toolchains.
