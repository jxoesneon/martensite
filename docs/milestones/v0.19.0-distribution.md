# Milestone Specification: v0.19.0 — Distribution

## 1. Executive Summary & Objectives

Milestone `v0.19.0` delivers end-user distribution artifacts for the
`cargo-martensite` toolchain and demo applications: native installers
(WiX / DMG / Flatpak), Ed25519-signed update manifests, and pre-built CLI
binaries attached to GitHub Releases.

**Status: tentatively scoped.** This milestone exists because earlier
planning documents attached installer/update scope to "v1.0.0". It may be
descoped to post-1.0 by ADR without blocking `v1.0.0-rc.1`; the decision
must be recorded before the RC is tagged.

Running distribution on a `0.x` tag first is deliberate: it exercises the
packaging and signing pipeline before the v1.0.0 release depends on it.

---

## 2. Target Crates & Modules

- `tools/cargo-martensite` (binary artifact for distribution)
- `examples/industrial_dashboard` (installable demo vehicle)
- `.github/workflows/` (release asset builds, signing, attestations)

---

## 3. Entry Criteria

- `v0.18.0` released.
- Scope confirmed by ADR (retain, reduce, or defer post-1.0).

---

## 4. Architectural Deliverables & Implementation Specifications

### 4.1. Pre-built CLI Binaries

- `cargo-martensite` release binaries for `x86_64`/`aarch64` macOS,
  `x86_64` Windows, `x86_64`/`aarch64` Linux, built in CI and attached to
  the GitHub Release.

### 4.2. Native Installers

- **Windows:** WiX `.msi` for `cargo-martensite` + demo app.
- **macOS:** signed + notarized `.dmg`.
- **Linux:** Flatpak manifest + bundle for the demo app.

### 4.3. Signed Updates

- Ed25519-signed update manifest scheme (TUF-style or equivalent);
  public key distribution documented; verification path in
  `cargo-martensite self-update` or documented as design-only.

### 4.4. Provenance

- Build attestations (SLSA provenance or `cargo dist`-equivalent metadata)
  for published artifacts.

---

## 5. Exit Criteria & Verification Gates

1. CI builds installers for all three desktop OSes from the tag.
2. Signed-update manifest verified end-to-end (sign → publish → verify).
3. Artifacts attached to the `v0.19.0` GitHub Release via the gated
   pipeline.
4. Standard local gates green.

---

## 6. Risk Matrix & Mitigations

| Risk Description | Probability | Severity | Mitigation Strategy |
| :--- | :--- | :--- | :--- |
| macOS signing/notarization needs Apple Developer account | High | Medium | ADR may defer signing to post-1.0; unsigned DMG is a documented fallback. |
| Scope too large for pre-RC window | Medium | Low | Milestone is explicitly descopable; partial delivery (binaries only) is acceptable. |
| Update mechanism ships unaudited crypto | Medium | High | Ed25519 via `ed25519-dalek`/`ring` only; no hand-rolled verification. |
