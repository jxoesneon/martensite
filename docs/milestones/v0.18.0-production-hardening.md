# Milestone Specification: v0.18.0 — Production Hardening & Dogfooding

## 1. Executive Summary & Objectives

Milestone `v0.18.0` converts Martensite's breadth into verified depth ahead
of the v1.0.0 release-candidate line. It contains no new feature surface:
every deliverable either closes a documented verification gap, hardens an
existing guarantee, exercises the framework with real application code, or
builds the tooling that makes the eventual API freeze mechanical rather than
conventional.

**Scope rule:** work that requires hardware/runners not yet provisioned is
either scheduled on real infrastructure or formally descoped with its public
claim downgraded — it is not carried silently into the RC.

---

## 2. Target Crates & Modules

- Workspace-wide (API audit, docs quality, lint policy)
- `martensite-vello` (residual `todo!()` stubs)
- `martensite-font-fallback`, `martensite-text-reference` (Windows exclusion)
- `martensite-clipboard-platform` (Wayland backend gap)
- `martensite-accesskit-winit` (vendored-fork exit plan)
- `cargo-martensite`, `martensite-devtools` (remaining perf gates)
- `examples/industrial_dashboard` (dogfooding vehicle)
- `benches/bench_suite` (competitive baselines)
- `.github/workflows/` (semver-checks, reproducible builds)

---

## 3. Entry Criteria

- `v0.17.0` released and CI-green on the tag.
- Roadmap reconciliation committed (this document, `INDEX.md`, `ROADMAP.md`,
  `v1.0.0-production-release.md` agree on the sequence).

## 4. Architectural Deliverables & Implementation Specifications

### 4.1. API Surface Audit & Freeze Tooling

- Enumerate the complete public API of every publishable crate; classify
  each item stable vs experimental.
- Finalize the `unstable-*` feature-flag inventory; gate every experimental
  item behind an explicit flag.
- Wire `cargo-semver-checks` into CI (release PRs + tags) so the freeze is
  mechanically enforced from v0.18.0 onward.
- Refresh `docs/API_FREEZE_AUDIT.md` (currently v0.11.0-era; unsafe-exception
  list must match the ten crates in `AGENTS.md`).
- Deprecation policy and MSRV policy (1.89.0) documented.

### 4.2. Verification Honesty Pass

- `docs/PLATFORM_SUPPORT.md` states verified vs compile-verified status
  precisely for every tier (wasm32, iOS, Android are compile-verified until
  their env-gated legs run).
- Every env-gated leg in `WORKING_ON.md` is either scheduled on real
  infrastructure or formally descoped with its claim downgraded:
  - `MARTENSITE_WEB_BROWSER` playwright run
  - `MARTENSITE_IOS_SIM_TESTS` simulator adapter test
  - `MARTENSITE_ANDROID_DEVICE` on-device test
  - Windows MF/DXGI runtime decode + DXGI NV12/P010 zero-copy
  - VAAPI runtime decode (`docker run --device /dev/dri`)
  - 4K120 gate on non-Apple GPU runners
  - AT harness legs (NVDA / VoiceOver / Orca)
  - 48-hour fuzz soak (`docker/fuzz`)

### 4.3. Residual Code Hardening

- `martensite-vello/src/wgpu_engine.rs`: replace the three `todo!()` panic
  paths (image/buffer-range proxy branches) with real error paths or
  implementations.
- `martensite-font-fallback` and `martensite-text-reference`: resolve the
  `windows` 0.61 DirectWrite API mismatch so they rejoin the Windows build,
  or document the exclusion as permanent.
- `martensite-clipboard-platform`: add the missing Wayland clipboard backend
  (X11-only today) or document Wayland as unsupported for clipboard.
- Replace the remaining fixed `thread::sleep` calls in
  `martensite-clipboard` tests and `martensite-devtools::tracy` with bounded
  polling.

### 4.4. Remaining Performance Gates

- Hot reload `<350 ms` (`cargo-martensite/tests/hot_reload_latency.rs`):
  add a CI assertion or formally relax the target.
- Tracy overhead `<0.1 ms/frame`: CI assertion or relaxation.
- Theme-transition zero-allocation: add a gate or formally drop the claim.

### 4.5. Dependency & Vendored-Fork Hygiene

- Track `winit` 0.31 toward stable; document the `martensite-accesskit-winit`
  removal plan once upstream supports it.
- `naga` 29/30 dedup: monitor upstream `vello_shaders`; document interim
  exemption.
- `martensite-bevy` git pin → released version when upstream ships wgpu-30.
- Document maintenance policy for `martensite-vello` and
  `martensite-cosmic-text` (re-sync cadence, patch discipline).

### 4.6. Dogfooding & Competitive Benchmarks

- Grow `examples/industrial_dashboard` into the full workstation demo
  (DataGrid + docking + media + shell chrome + devtools HUD) — the primary
  API-friction discovery vehicle before the freeze.
- Extend `benches/bench_suite` with egui/iced-comparable baselines for the
  shared primitives (layout throughput, signal propagation, text shaping)
  and publish results in `docs/BENCHMARKS.md`.

### 4.7. Documentation & Distribution Prep

- Four end-to-end tutorials (per v1.0.0 §4.2): `cargo-martensite` init,
  reactive state, custom widget, a11y validation.
- Docs-quality review pass: parameter/return/failure-mode coverage on
  primary public APIs (beyond `missing_docs` mechanics).
- Reproducible-build verification across Linux/macOS/Windows CI runners.
- `docs/MIGRATION_GUIDE_0x_to_1x.md` updated to the post-v0.17.0 API.

---

## 5. Exit Criteria & Verification Gates

1. `cargo-semver-checks` active in CI and clean against `v0.17.0`.
2. Every env-gated leg executed or formally descoped; `PLATFORM_SUPPORT.md`
   and `WORKING_ON.md` agree with reality.
3. Zero `todo!()`/`unimplemented!()` in non-doc code of shipping crates.
4. All standard local gates green (fmt, clippy ×2, tests ×2, doctests,
   `cargo doc -D warnings`, deny, audit, vet) + target-checks matrix.
5. Workstation demo builds and runs on macOS; benchmark baselines published.
6. Tagged `v0.18.0` through the full gated publish pipeline.

---

## 6. Risk Matrix & Mitigations

| Risk Description | Probability | Severity | Mitigation Strategy |
| :--- | :--- | :--- | :--- |
| Env-gated legs can't get hardware in time | High | Medium | Formal descope path is an accepted exit; claims downgraded, not hidden. |
| API audit surfaces design changes late | Medium | High | Audit runs first; API changes land in v0.18.0, never after rc.1. |
| Vendored-fork exits blocked upstream | Medium | Low | Exit plans documented; retention with policy is an acceptable outcome. |
| Dogfooding finds real API friction | High | Low | That is the deliverable — findings land as fixes before the freeze. |
