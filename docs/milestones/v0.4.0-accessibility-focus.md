# Milestone Specification: v0.4.0 — Accessibility & Focus

## 1. Executive Summary & Objectives
Milestone `v0.4.0` implements first-class platform accessibility integration and a deterministic 2D spatial keyboard navigation engine. It maps the Martensite `WidgetArena` directly into the AccessKit semantic hierarchy, ensuring complete compatibility with Windows UI Automation, macOS NSAccessibility, and Linux AT-SPI2, while implementing projected-beam 2D directional navigation and modal focus trapping.

---

## 2. Target Crates & Modules
- **`martensite-access`**:
  - `adapter`: `AccessKitAdapter`, incremental `TreeUpdate` generation, mapping `WidgetId` to AccessKit `NodeId`.
  - `properties`: Accessibility roles, names, descriptions, states (expanded, checked, disabled).
  - `actions`: Dispatching accessibility actions (`Action::Click`, `Action::Focus`, `Action::SetValue`) to the event pipeline.
- **`martensite-focus`**:
  - `manager`: `FocusManager`, active focus tracking, tab navigation ordering.
  - `spatial`: 2D projected-beam directional algorithm (arrow key navigation).
  - `scope`: Modal `FocusScope` stack with focus trapping and auto-restoration upon modal dismiss.

---

## 3. Entry Criteria
- `v0.3.0` complete: Text measurement and two-pass layout operational.
- Base widget components expose bounding boxes and visibility states.

## 4. Architectural Deliverables & Implementation Specifications

### 4.1. AccessKit Incremental Tree Synchronization
Rather than regenerating full accessibility trees on every state change, `martensite-access` synchronizes diffs incrementally:
- Each interactive node produces an `accesskit::Node` payload containing bounding rectangles in window coordinates, semantic roles (`Role::Button`, `Role::TextInput`, `Role::CheckBox`), and live state bitmasks.
- Dirty bit tracking identifies only mutated or reparented nodes, dispatching lightweight `TreeUpdate` packages to the OS accessibility subsystem.
- Thread-safe mapping: AccessKit updates are emitted synchronously following layout finalization, preventing race conditions where screen readers query stale coordinate boundaries.

### 4.2. Projected-Beam 2D Spatial Focus Algorithm
For gamepads, TV remotes, and keyboard navigation across non-linear widget grids, `martensite-focus` implements a directional vector scoring algorithm:

$$	ext{Score}(A, B, ec{d}) = lpha \cdot 	ext{Distance}(A, B) + eta \cdot 	ext{AngularDeviation}(ec{AB}, ec{d})$$

- $ec{d} \in \{(0, -1), (0, 1), (-1, 0), (1, 0)\}$ represents the navigation direction.
- Candidates behind the source node or outside an $80^\circ$ forward cone are rejected immediately.
- The candidate with the minimum score is awarded focus. If multiple candidates have equivalent scores, layout tree order serves as the deterministic tie-breaker.

### 4.3. Modal FocusScope Stack & Focus Trapping
To prevent keyboard navigation from escaping active modal dialogs, popovers, or context menus:
- A `FocusScope` pushes onto the active stack when a modal opens, capturing the previously focused `WidgetId`.
- Directional and Tab navigation cycle exclusively within the active scope boundaries.
- When the modal dismisses, the scope pops, and focus restores automatically to the recorded prior node. If the prior node was deleted during modal presentation, focus gracefully falls back to the nearest visible sibling.

## 5. Exit Criteria & Verification Gates
1. **Accessibility Compliance Gate:**
   - 100% of interactive widgets in the standard library expose valid AccessKit roles, accessible labels, and action handlers.
   - Screen reader test passes on Windows (Narrator) and macOS (VoiceOver), verifying correct readout of label and value changes.
2. **Spatial Navigation Determinism:**
   - 2D grid test suite with irregular spacing passes 100% of directional transitions across all four cardinal directions.
3. **Focus Trapping Verification:**
   - Automated tests confirm Tab and Shift+Tab keypresses cannot escape an active modal scope.

## 6. Risk Matrix & Mitigations
| Risk Description | Probability | Severity | Mitigation Strategy |
| :--- | :--- | :--- | :--- |
| OS accessibility query causes IPC freeze | Low | High | Decouple AccessKit event pump from main UI thread; emit batched updates asynchronously. |
| Modal dismiss leaves focus in undefined state | Medium | Medium | Implement automatic fallback to root container if prior focused node was removed from arena. |
