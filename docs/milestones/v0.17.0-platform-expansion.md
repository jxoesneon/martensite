# Milestone Specification: v0.17.0 — Platform Expansion

## 1. Executive Summary & Objectives

Milestone `v0.17.0` is the largest breadth milestone: it completes the
core widget floor, adds web/wasm and iOS/Android targets, and ships a
time-travel debugger. These are the four competitive gaps identified
against egui/iced/Slint/Makepad.

The headline targets:

- **Six widgets with full ARIA APG contracts** — slider, radio group,
  dropdown/listbox, scrollview, tabs, tooltip — each with correct
  AccessKit roles/actions, keyboard interaction, and a new overlay/popup
  layer primitive they depend on.
- **`wasm32-unknown-unknown` runs the framework** — WebGPU where
  available, TinySkia CPU fallback where not; honest about the web
  accessibility gap (no AccessKit web adapter exists — we build a
  hidden-DOM/ARIA bridge or document the limitation).
- **iOS and Android run the framework** — winit UIKit/`GameActivity`
  backends, wgpu Metal/Vulkan, `accesskit_ios`/`accesskit_android`.
- **Time-travel debugging** — hybrid command-ledger + snapshot replay
  over the retained arena and reactive graph (not iced's
  message-log model, which our architecture doesn't share).

## 2. Target Crates & Modules

- **`martensite` widgets (NEW files under `src/widgets/`):** `slider.rs`,
  `radio.rs`, `dropdown.rs`, `scrollview.rs`, `tabs.rs`, `tooltip.rs`.
- **`martensite-core` / `martensite-render`**: overlay/popup layer
  primitive (z-ordered paint layer above content; click-outside and
  Escape dismissal; viewport clamping) — required by dropdown and
  tooltip.
- **`martensite-window`**: pointer capture API; web canvas backend;
  mobile lifecycle (`can_create_surfaces`/`can_destroy_surfaces`),
  `safe_area()` insets, touch/`PointerKind` routing, IME
  (`request_ime_update`, hidden-input overlay on web).
- **`martensite-wgpu`**: wasm instance creation
  (`Backends::BROWSER_WEBGPU` + `new_instance_with_webgpu_detection`,
  `webgl` downlevel fallback), mobile surface lifecycle.
- **`martensite-access`**: `accesskit_ios` `SubclassingAdapter`,
  `accesskit_android` `InjectingAdapter` (`embedded-dex`), web
  hidden-DOM/ARIA bridge (new; no upstream adapter exists).
- **`martensite-text` / `martensite-cosmic-text`**: wasm font loading —
  bundled fonts via `fontdb::Source::Binary` + `fetch`; no system fonts
  on wasm.
- **`martensite-devtools`**: `timemachine` — `CommandJournal` on
  `martensite-history` `ChangeOp`s, periodic `ArenaSnapshot` +
  `SignalSnapshot`, `scrub`/`replay` API, `#[cfg]`-gated overhead.
- **`martensite-reactive`**: source-write journal (record `Signal::set`
  writes with monotonic index; `Memo`s recompute lazily on pull).
- **`martensite-clipboard`/`martensite-dnd`**: web backends —
  `navigator.clipboard` (gesture-gated, COOP/COEP-aware) and HTML5
  `DataTransfer` drops.
- **`martensite-accesskit-winit`**: continue vendored maintenance — the
  0.31 beta remains ahead of upstream `accesskit_winit` (0.33.2 supports
  only winit 0.30).

## 3. Entry Criteria

## 4. Architectural Deliverables & Implementation Specifications

### 4.1. Widget Breadth — per-widget contract (ARIA APG + AccessKit)

| Widget | Role / Actions | Keyboard contract | Mechanics |
|---|---|---|---|
| Slider | `Role::Slider`, `SetValue`+`NumericValue`, `numeric_value(_step)`, `min/max_numeric_value` | Arrows step; Home/End → min/max; PgUp/PgDn large step | Pointer capture on thumb drag; rail click jumps; horizontal+vertical; `aria-valuetext` formatter |
| Radio | `Role::RadioGroup` container + `Role::RadioButton`, `CheckedState` | Group = one tab stop; arrows move+select; Space selects | Roving tabindex; single-checked invariant |
| Dropdown | `Role::ComboBox` (expanded state) → `Role::ListBox`/`ListBoxOption` | Arrows/Enter/Space; Escape closes; printable typeahead; Home/End | Popup in overlay layer; `ScrollView` inside; close on outside-click/select; `aria-activedescendant` |
| ScrollView | `Role::ScrollBar` on bars, `SetScrollOffset`, `ScrollIntoView` | Arrows/PgUp/PgDn/Home/End | Smart scrollbars (show on overflow); wheel+drag+thumb; nested scroll chaining at bounds; scroll anchoring (`S1 = S0 + (L1−L0)`); rubber-band via `martensite-motion`; virtual-scroll option |
| Tabs | `Role::TabList`/`Tab`/`TabPanel`, `aria-selected`, `aria-controls` | Arrows cycle (auto- or manual-activate); Home/End; Tab into panel | Roving tabindex; panel visibility sync |
| Tooltip | `Role::Tooltip`, `aria-describedby` on trigger, `Show/HideTooltip` | Focus shows; Escape/blur hides | 500–1000ms hover delay (configurable); non-focusable; no interactive children; overlay layer; viewport clamp; WCAG 1.4.13 hoverable |

All six are Taffy leaves managing internal `Flex`/`Stack` children
(existing two-level layout convention), with AccessKit nodes emitted
through `martensite-access` from day one — no retrofit.

### 4.2. Overlay/Popup Layer

New render-layer concept above the content pass: dropdowns, tooltips,
(and future context menus/dialogs) paint into it; it owns
outside-click dismissal, Escape handling, and z-order. Not a separate
OS window in v0.17.0 — in-window overlay only.

### 4.3. Web Target (`wasm32-unknown-unknown`)

- `martensite-wgpu`: dual-feature `webgpu`+`webgl`; detect WebGPU →
  `BROWSER_WEBGPU`, else WebGL2 downlevel limits, else TinySkia
  raster fallback (Vello is compute-based — **no WebGL2 path**).
  `fragile-send-sync-non-atomic-wasm`; COOP/COEP documented.
- `martensite-window`: `WindowExtWeb::canvas`, `EventLoopExtWeb::spawn_app`,
  `ControlFlow::Poll`/rAF model; manual canvas backing-store DPI scaling.
- Text: bundled fonts via `fontdb::Source::Binary` + `fetch`-loaded
  font sources; `cosmic-text` `wasm-web` feature; no system fonts.
- IME: hidden `<input>` overlay for composition (the approach egui/
  Makepad use — canvas has no native IME).
- Clipboard: async `navigator.clipboard`, user-gesture + secure-context
  gated.
- **Accessibility — the honest gap:** there is no AccessKit web adapter.
  Options: (a) build a hidden-DOM/ARIA-live-region bridge translating
  the AccessKit tree (new work, scoped here), (b) document web a11y as
  degraded for v0.17.0. The spec commits to (a) at a minimal viable
  level — a live-region announcer + focusable-role DOM mirror — and
  flags full DOM mirroring as v1.0+ hardening.

### 4.4. iOS

- winit UIKit backend; wgpu Metal (`Backends::METAL`); surface create in
  `can_create_surfaces`.
- `Window::safe_area()` → `PhysicalInsets` (implemented on iOS in
  winit 0.31).
- `accesskit_ios` 0.1.x `SubclassingAdapter` — **Phase-1 upstream
  maturity** (basic traits/properties; editable text incomplete).
  Document the upstream limitation honestly.
- Packaging: `cargo-mobile2` + Xcode project generation; `staticlib`
  for `aarch64-apple-ios(-sim)`.

### 4.5. Android

- winit + `android-activity` with **`GameActivity`** — NOT
  `NativeActivity` (IME events unreliable and AccessKit panics there —
  eframe disables a11y on it).
- wgpu Vulkan first-class + GLES downlevel; surface destroy in
  `can_destroy_surfaces`, recreate on `resumed`.
- `accesskit_android` 0.7.x `InjectingAdapter` + `embedded-dex` (JNI).
- `Window::safe_area()` returns zeros on Android — read `WindowInsets`
  via platform code until winit lands it.
- Packaging: `cdylib` + `cargo-apk2`/`xbuild`.

### 4.6. Time-Travel Debugger (`martensite-devtools::timemachine`)

Our architecture is retained-arena + push-pull signals — not Elm's
message→update→view fold — so iced `comet`'s pure message-log replay
doesn't transfer directly. The design is a **hybrid**:

1. **Command journal** — user-meaningful mutations recorded as
   `ChangeOp`s in `martensite-history` (branching + LCA navigation for
   free).
2. **Periodic snapshots** — `WidgetArena` hot/cold + `ReactiveRuntime`
   source-signal values checkpointed every N frames/actions.
3. **Replay** — restore nearest snapshot, re-apply journal forward;
   `Memo`s recompute lazily during pull phase (record *source* writes
   only).
4. **Determinism contract** — `VirtualClock`, seeded RNG, deterministic
   task ordering, mocked I/O during replay; `debug::disable`-style
   guard so replayed commands don't re-journal.

All gated behind a `devtools-timemachine` feature — zero production
overhead.

## 5. Exit Criteria & Verification Gates

| Gate | Criterion | Verification |
|------|-----------|--------------|
| Widgets | All six widgets pass ARIA APG keyboard + AccessKit role/action conformance | `martensite-test` harness + AccessKit tree assertions |
| Overlay | Popup dismissal (Escape/outside), viewport clamp, z-order | Unit + golden frame |
| Web | `wasm32` build renders via WebGPU; TinySkia fallback on WebGL2-only path | `trunk`-built example + headless browser check (`#[ignore]` CI) |
| iOS | Example app runs on simulator/device; a11y tree exported | `cargo-mobile2` build + `#[ignore]` device gate |
| Android | Example APK runs; GameActivity IME works; AccessKit injects | `cargo-apk2` build + `#[ignore]` device/emulator gate |
| Time-travel | Journal+snapshot replay reproduces a recorded interaction deterministically | VirtualClock test — replayed state == recorded state |
| No desktop regression | All existing gates stay green | Full CI suite |

## 6. Dependencies

- Web: `wasm-bindgen`, `web-sys` (+`web_sys_unstable_apis`), `trunk`/
  `wasm-pack` tooling.
- iOS: `accesskit_ios`, `cargo-mobile2`.
- Android: `accesskit_android` (+`embedded-dex`), `cargo-apk2`/`xbuild`.
- Time-travel: none new — reuses `martensite-history`/`martensite-test`.
- All platform deps feature-gated; default desktop build unaffected.

## 7. Unsafe Code Policy

- Mobile glue (`accesskit_ios`/`accesskit_android` JNI/objc boundaries)
  goes in a new allowed-unsafe `martensite-access-platform` crate —
  consistent with the workspace's unsafe-isolation convention; update
  `AGENTS.md`.
- Web target is safe Rust (wasm-bindgen externs are not `unsafe`).

## 8. Explicit Risks (from research)

- **winit 0.31-beta + accesskit_winit**: upstream `accesskit_winit`
  0.33.2 supports only winit 0.30; our vendored fork carries 0.31-beta.3
  support. Mobile/web work must extend the fork, not wait on upstream.
- **Web a11y**: no adapter exists anywhere; our bridge is new work and
  its v0.17.0 scope is deliberately minimal.
- **Android safe-area**: not in winit; needs platform code.
- **Vello on web**: WebGPU-only; WebGL2 browsers get TinySkia.
