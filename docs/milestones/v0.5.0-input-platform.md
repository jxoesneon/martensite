# Milestone Specification: v0.5.0 — Input & Platform

## 1. Executive Summary & Objectives
Milestone `v0.5.0` delivers comprehensive platform integration for OS clipboards, cross-window and system drag-and-drop, high-fidelity hit-testing with arbitrary affine transforms, and velocity-damped IME candidate positioning during kinetic scrolling.

## 4. Architectural Deliverables & Implementation Specifications

### 4.1. Process-Wide Detached Drag-and-Drop Sessions
To prevent dangling node references or crashes when a source window is closed during an active drag operation:
- Active drag payloads detach into an independent process-level `DndSession`.
- Payloads are wrapped in `Arc<dyn Any + Send + Sync>`.
- Even if the originating window or widget is evicted from the arena mid-flight, the session remains valid until the OS signals drop completion or cancellation.

```rust
pub struct DndSession {
    pub payload: std::sync::Arc<dyn std::any::Any + Send + Sync>,
    pub available_types: Vec<String>,
    pub source_window: Option<winit::window::WindowId>,
}
```

### 4.2. Robust Hit-Testing Under Affine Transformations
Hit-testing evaluates widgets in reverse Z-order using a two-stage pipeline:
1. **Stage 1 (Broad-Phase):** Axis-Aligned Bounding Box (AABB) rejection using `HotNode.bounds`.
2. **Stage 2 (Narrow-Phase):** Coordinate transformation into local widget space via inverse $3 	imes 3$ affine matrix.
3. **Singular Matrix Guard:** If the transformation matrix determinant is near zero ($|\det(M)| < 10^{-6}$, e.g. edge-on 3D perspective or scale zero), the hit-test safely returns false without panic or NaN propagation.
4. **Non-Rectangular Clip Verification:** Winding-number path evaluation tests points against rounded rectangles or custom clipping paths.

### 4.3. Damped Velocity Projection for Kinetic IME Cursor
When text input occurs within an actively scrolling container (touch fling or momentum scroll), the IME candidate window must track the caret without jitter or detachment:

$$P_{	ext{ime}}(t) = P_{	ext{caret}} + ec{v} \cdot \Delta t \cdot e^{-\lambda \Delta t}$$

- $ec{v}$ represents the current scroll velocity vector.
- $\lambda$ is an acceleration-bounded damping factor preventing overshoot on abrupt scroll termination or edge bounce.
- Bounding coordinates are clamped to the visible viewport bounds before emission to the OS IME context.

## 5. Exit Criteria & Verification Gates
1. **Cross-Window Drag & Drop Gate:**
   - Drag initiated in Window A drops successfully into Window B, even if Window A is closed programmatically while the drag is active.
2. **IME Positioning Gate:**
   - IME candidate bounding rect matches visible caret coordinates within 2 pixels during active scrolling at 1,000 px/sec.
3. **Hit-Testing Matrix Inversion Safety:**
   - 100,000 synthetic clicks across collapsed, scaled, and rotated widgets produce zero panics, NaNs, or memory errors.

## 6. Risk Matrix & Mitigations
| Risk Description | Probability | Severity | Mitigation Strategy |
| :--- | :--- | :--- | :--- |
| Wayland clipboard paste hangs on unresponsive client | Medium | High | Lazy evaluation timeout; isolate clipboard IPC on background thread with 500ms deadline. |
| Non-rectangular clip hit-testing degrades performance | Low | Medium | Strict AABB early exit; only evaluate winding number on confirmed bounding box overlap. |
