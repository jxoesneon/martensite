# Milestone Specification: v0.13.0 — Modern Shell & Platform

## 1. Executive Summary & Objectives

Milestone `v0.13.0` delivers native platform shell integration: Windows 11
system materials (Mica, Mica Alt, Acrylic) with Snap Layouts, macOS Liquid
Glass vibrancy with appearance-aware materials, and Wayland client-side
decorations with fractional-scale DPI and StatusNotifierItem system-tray
support. These close the gap between Martensite's cross-platform rendering
engine and the native desktop chrome that end users expect.

The headline performance and correctness targets are:

- **DWM backdrop switch < 8 ms** — switching between Mica/Acrylic/solid
  must complete in under 8 ms on a reference Windows 11 runner.
- **Zero blur under fractional Wayland DPI** — CSD shadows rendered at
  physical buffer resolution (logical × fractional_scale), never
  upscaled from 1x.
- **Native CSD hit-testing** — title-bar drag, resize edges, and window
  buttons must hit-test correctly under all three desktop environments
  (GNOME, KDE, wlroots compositors).

## 4. Architectural Deliverables & Implementation Specifications

### 4.1. Cross-Platform Backdrop System (`martensite-shell::backdrop`)

A `BackdropMaterial` enum describes the system material requested by the
theme:

```rust
pub enum BackdropMaterial {
    None,
    Mica,
    MicaAlt,
    Acrylic,
    Transient,
    Vibrancy(VibrancyMaterial),
}

pub enum BackdropMode {
    Opaque,
    Transparent,
}
```

The `BackdropController` trait is implemented per-platform:

```rust
pub trait BackdropController {
    fn set_material(&mut self, window: &dyn Window, material: BackdropMaterial);
    fn current_material(&self) -> BackdropMaterial;
    fn mode(&self) -> BackdropMode;
    fn supports_material(&self, material: BackdropMaterial) -> bool;
}
```

`BackdropMode::Transparent` signals the render pipeline to use a transparent
clear color and `CompositeAlphaMode::PreMultiplied`; `Opaque` uses the
existing solid-color path.

### 4.2. Windows 11 Mica / Acrylic & Snap Layouts

**DWM System Materials:**
- `DwmSetWindowAttribute` with `DWMWA_SYSTEMBACKDROP_TYPE`:
  - `DWMSBT_MAINWINDOW` → Mica
  - `DWMSBT_TRANSIENTWINDOW` → Mica Alt
  - `DWMSBT_TABBEDWINDOW` → Acrylic
- `DWMWA_USE_IMMERSIVE_DARK_MODE` for title-bar dark-mode sync.
- `DWMWA_WINDOW_CORNER_PREFERENCE` for rounded-corner toggle.
- `DWMWA_CAPTION_COLOR` and `DWMWA_TEXT_COLOR` for custom title-bar colors.
- Fallback: if `DwmSetWindowAttribute` fails (pre-Win11), fall back to
  solid color from `BackdropFallbackColor` theme token.

**Snap Layouts:**
- Handle `WM_NCHITTEST` with snap-zone gesture detection.
- `ISnapLayouts` COM interface for the snap flyout.
- `WM_NCLBUTTONDOWN` on the maximize button triggers the snap flyout.
- Cross-platform `SnapLayout` abstraction in `martensite-shell::snap`.

**Unsafe surface:** `#![allow(unsafe_code)]` in
`platform_impl/windows.rs` only. All Win32 calls via the `windows` crate.

### 4.3. macOS Liquid Glass Vibrancy

**Vibrancy Materials:**
- `NSVisualEffectView` for macOS 14 and earlier (backward compat):
  - `setMaterial:` with `NSVisualEffectView.Material` enum.
  - `setBlendingMode:` (`behindWindow` vs `withinWindow`).
  - `setState:` (active, inactive, followsWindowActiveState).
- macOS 26+ Liquid Glass:
  - New `NSGlassEffectView` / `CALayer.material` API.
  - Appearance-aware: re-evaluate material on `NSAppearance` change.
- Add vibrancy view as subview of window's content view, behind the
  wgpu Metal layer.

**Appearance Sync:**
- `NSAppearance` change notifications propagate as
  `WindowEventOutcome::ThemeAppearanceChanged`.
- The theme system triggers a 150 ms `ThemeDiff` transition (existing
  `martensite-wgpu::theme_transition`).

**Unsafe surface:** `#![allow(unsafe_code)]` in
`platform_impl/macos.rs` only. All Objective-C calls via `objc2`/`icrate`.

### 4.4. Wayland CSD & Fractional Scale

**winit feature flags:**
- Add `"wayland"` to winit features in workspace `Cargo.toml`.
- Pulls in `wayland-client`, `wayland-protocols`, `sctk`.

**Fractional Scale:**
- `wp_fractional_scale_v1::preferred_scale` event carries a fractional
  scale (e.g. 1.5x).
- `DpiScale` already stores `f64`; the existing
  `WindowEventOutcome::ScaleFactorChanged(f64)` plumbing handles this.
- Per-surface fractional scale: each `wl_surface` can have a different
  scale. The buffer size = logical × fractional_scale.
- `SurfaceWrapper::resize` must use the fractional-scaled physical
  dimensions, not the logical ones.

**Client-Side Decorations:**
- `CsdController` draws title bar, window buttons (close/min/max), resize
  handles, and window shadows.
- CSD rendering goes through `PaintList` (normal render pipeline), not a
  system material.
- Hit-testing integrates with existing `hit_test.rs`:
  - Title bar drag region.
  - Resize edges (8 directions).
  - Window button regions.
- `CsdTheme` varies by desktop environment:
  - GNOME: Adwaita-style (rounded buttons, centered title).
  - KDE: Breeze-style (square buttons, left-aligned title).
  - Generic/wlroots: minimal rounded title bar.

**CSD Shadows:**
- `PaintList::push_blurred_rect` — new paint command for GPU blur.
- Shadow rendered at physical buffer resolution (logical ×
  fractional_scale) to avoid upscaling blur.
- Shadow blur radius from `CsdShadowBlur` theme token.

**StatusNotifierItem:**
- `org.kde.StatusNotifierItem` D-Bus protocol.
- Registers app on session bus, exports icon + tooltip + status.
- Handles activation clicks.
- Self-contained module in `martensite-shell::status_notifier`.
- Uses `zbus` crate for D-Bus.

### 4.5. Theme System Extensions

New `TokenKey` variants:
- `BackdropMaterial` — enum value selecting the system material.
- `BackdropTintOpacity` — f32, 0.0–1.0 tint opacity for Mica/Acrylic.
- `BackdropFallbackColor` — Oklab color for non-supporting platforms.
- `CsdTitleBarHeight` — f32, title-bar height in physical pixels.
- `CsdButtonRadius` — f32, window-button corner radius.
- `CsdShadowBlur` — f32, CSD shadow blur radius.
- `CsdShadowColor` — Oklab color for CSD shadow.
- `VibrancyMaterial` — enum value for macOS-specific material selection.

`ThemeDictionary` must support platform-conditional defaults:
- Windows: Mica/Acrylic with solid fallback.
- macOS: Vibrancy with solid fallback.
- Linux/Wayland: Solid color (no system material).

### 4.6. Surface & Render Pipeline Changes

**Surface Alpha Negotiation:**
- `SurfaceWrapper::configure` gains a `BackdropMode` parameter.
- `BackdropMode::Opaque` → `CompositeAlphaMode::Opaque`.
- `BackdropMode::Transparent` → `CompositeAlphaMode::PreMultiplied`.
- Default remains `Auto` for backward compatibility.

**Transparent Clear:**
- When `BackdropMode::Transparent`, the renderer's clear color is
  `(0, 0, 0, 0)` and the background fill rect is skipped.
- `RenderOrchestrator` queries the active `BackdropMode` and adjusts.

**Blur Filter:**
- `PaintList::push_blurred_rect` — new paint command.
- GPU blur pass (two-pass Gaussian: horizontal + vertical).
- Used for CSD shadows and Liquid Glass fallback on Linux.
- Must be pixel-perfect at fractional DPI (render at physical resolution).

## 6. Dependencies

New workspace dependencies:
- `windows` (Win32 + WinUI, Windows-only, optional feature)
- `objc2` / `icrate` (macOS-only, optional feature)
- `zbus` (D-Bus for StatusNotifierItem, Linux-only, optional feature)

The `martensite-shell` crate uses `#[cfg(target_os = ...)]` gating for
platform-specific backends. Non-active platforms compile to a stub
`BackdropController` that returns `BackdropMaterial::None`.

## 7. Unsafe Code Policy

`martensite-shell` joins the allowed-unsafe list:
- `platform_impl/windows.rs` — Win32/COM FFI.
- `platform_impl/macos.rs` — Objective-C runtime FFI.

Wayland CSD and StatusNotifierItem are safe Rust (via `wayland-client`
and `zbus`). No new unsafe surface for Linux.

`AGENTS.md` must be updated to list `martensite-shell` in the
allowed-unsafe section.
