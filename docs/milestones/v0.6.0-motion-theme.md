# Milestone Specification: v0.6.0 — Motion & Theme

## 1. Executive Summary & Objectives
Milestone `v0.6.0` integrates continuous analytical spring physics and a perceptually uniform color engine. It eliminates iterative numerical physics drift by implementing closed-form spring equations with $C^1$ velocity continuity, and establishes an Oklab-driven theme pipeline supporting smooth color morphing via GPU uniform transition shaders.

---

## 2. Target Crates & Modules
- **`martensite-motion`**:
  - `spring`: `SpringSolver`, `SpringConfig` (stiffness, damping, mass), closed-form continuous equations.
  - `animation`: Driver management, continuous interpolation, velocity handoff upon interruption.
- **`martensite-theme`**:
  - `oklab`: `Oklab` and `Oklch` color representations, perceptual lightness, chroma, and hue.
  - `tokens`: Design token dictionary, light/dark mode definitions.
  - `gpu_transition`: Theme morphing uniform buffers and WGSL transition shaders.

### 4.2. Oklab Perceptual Color Pipeline & Gamut Mapping
Color interpolation in standard non-linear sRGB space produces dark, muddy banding along hue boundaries. `martensite-theme` executes all color blending in Oklab:
- Linear transformation from linear sRGB to cone responses ($LMS$), cube root nonlinearity, and conversion to $L, a, b$.
- Hue-preserving chroma reduction algorithm for out-of-gamut display targets.
- Contrast calculation adhering to WCAG 2.1 contrast formulas and APCA (Advanced Perceptual Contrast Algorithm) guidelines.

### 4.3. GPU Theme Transition Uniforms
Theme swaps (light mode $\leftrightarrow$ dark mode) do not re-run component view declarations:
- Theme token values upload into a uniform buffer (`ThemeUniforms`).
- A smooth 150ms transition parameter ($t \in [0.0, 1.0]$) blends color palettes directly in the fragment shader.

## 5. Exit Criteria & Verification Gates
1. **Analytical Accuracy Gate:**
   - Spring solver position matches closed-form analytical solutions to within $< 10^{-6}$ precision across all damping regimes.
2. **Gesture Interruption Continuity:**
   - Velocity continuity test confirms zero acceleration discontinuity when gestures interrupt active spring motions.
3. **Theme Transition Performance:**
   - Dynamic theme switch completes across a 5,000-widget scene with zero CPU allocations and continuous 60fps/120fps presentation.
